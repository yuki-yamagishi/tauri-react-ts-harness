# 汎用 AI駆動開発・検証ハーネス スキル

このスキルは、**Tauri + React + TypeScript** アプリケーションの開発・検証・コミットを最高品質で行うための公式ワークフローガイドです。

---

## 1. 開発フロー（標準 4 ステップ）

```
[ 1. 事前検証 ] ────> [ 2. 作業計画 ] ────> [ 3. 実装 & 自動検証 ] ────> [ 4. コミット & プッシュ ]
  (docs/pre_...)        (docs/impl_...)        (npm run check)            (Conventional Commits)
```

---

## 2. ドキュメント分離ルール (`docs/` 配下)

すべての設計・検証資産はリポジトリの `docs/` 配下に完全な日本語で記録・保守します：

1. **事前検証ログ (`docs/pre_phase_verification.md`)**:
   - 4つの検証軸（①技術的ボトルネック, ②UX・エッジケース, ③データ永続性・互換性, ④テスト自律性）を評価。
2. **実装計画書 (`docs/implementation_plan.md`)**:
   - 事前検証の議論は含めず、純粋な変更ファイル一覧、実装内容、検証手順のみを簡潔に記載。
3. **実装成果レポート (`docs/walkthrough.md`)**:
   - フェーズ完了時に達成内容、検証結果、コミット情報を記録。

---

## 3. ワンショット品質 & セキュリティゲート

変更後は必ず以下のコマンドで全件合格を確認します：

```bash
npm run check
```

**実行される自動検査**:
1. **シークレットスキャン (`node scripts/securityCheck.js`)**: APIキー・トークン・秘密鍵・個人情報の誤混入を自動検知。
2. **ドキュメント整合性検査 (`node scripts/docCheck.js`)**: `docs/` 配下の必須ファイルの存在・内容充実度を検証。
3. **TypeScript 型検査 (`tsc --noEmit`)**: Strict モードでの型完全性の検証。
4. **単体・統合・UIテスト & カバレッジ (`vitest run --coverage`)**: コアロジック 90% 以上の網羅率。
5. **本番バンドルビルド (`vite build`)**: バンドル破損・CSSリンク・循環参照の検証。

---

## 4. Git コミット & プッシュ規約

* **接頭辞（Conventional Commits）を必ず付与**:
  - `feat:` 新機能追加
  - `fix:` バグ修正
  - `docs:` ドキュメント作成・更新
  - `chore:` ハーネス・依存関係・設定更新
  - `ci:` GitHub Actions ワークフロー変更
  - `test:` テストコード追加・修正
* **コミット ➔ 即時プッシュの完全一体化（必須）**:
  - コミット後は直ちに `git push origin main` を実行してリモートと完全同期させること。
  - `git status` で `Your branch is up to date with 'origin/main'.` を確認して完了とする。
* **文字化け防止**: すべてのファイルは UTF-8 (LF) で保存（`.gitattributes` で強制）。
* **言語標準**: すべてのドキュメント・解説は **完全日本語** で記述。
